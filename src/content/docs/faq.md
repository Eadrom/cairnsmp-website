## What edition of Minecraft does Cairn SMP use?

Cairn SMP is for **Minecraft: Java Edition** only. Bedrock Edition is not supported.

## What is the server address?

Use `play.cairnsmp.com`. Follow the full steps on the [How to Play page](/play/).

## Which Minecraft versions are supported?

Cairn SMP supports **Minecraft Java Edition 1.21 through 26.3**. The server runs 26.2, which gives the smoothest experience. On other versions, a few blocks and items added or changed since your version may look a little different.

## Is there a live server status or player count?

No, the website doesn’t show live server status or player counts.

## Is there a Discord?

Yes. Join using the permanent [Cairn SMP Discord invite](https://discord.gg/6p8UXyXMzr).

In-game chat and the `#server-chat` channel are linked both ways. Use `/discord link` in game to link your accounts and chat from Discord.

## How do I get help?

Email [support@cairnsmp.com](mailto:support@cairnsmp.com).
