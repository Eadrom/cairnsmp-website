Cairn SMP is a **Minecraft Java Edition** server. Bedrock Edition is not supported in V1.

<CopyAddress compact />

## Before you join

| Item | Details |
| --- | --- |
| Edition | Minecraft: Java Edition |
| Server address | `play.cairnsmp.com` |
| Supported version | Minecraft Java Edition 26.2 |
| Required client mods | None documented yet |
| Resource pack | No requirement documented yet |

## Add Cairn SMP to Multiplayer

1. Open **Minecraft: Java Edition**.
2. Choose **Multiplayer** from the main menu.
3. Select **Add Server**.
4. Give it a name such as “Cairn SMP”.
5. Enter `play.cairnsmp.com` as the server address.
6. Save the entry, select it, and choose **Join Server**.

## Take a moment before joining

Read the [server rules](/rules/) before you set out. The [features handbook](/features/) is here when you want to understand one of the server’s systems.
