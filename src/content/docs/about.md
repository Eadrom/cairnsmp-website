Cairn SMP started out as a server for Eadrom’s friends, guildmates and friends-of-friends. The goal now is to grow into a community of regular players, while Eadrom keeps developing new features to explore.

## The idea

A cairn is a marker built one stone at a time. It helps people find a route without turning the landscape into noise. That is a useful model for the server too: explore, contribute, and leave something helpful behind.

## What to expect

- Minecraft: Java Edition survival
- A small, growing community
- A practical player handbook
- No gambling and no pay-to-win
