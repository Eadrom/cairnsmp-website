Cairn SMP began primarily as a server for Eadrom’s friends, guildmates, and friends-of-friends. There is room for gradual outside growth, but the goal is a real small community—not a giant commercial network.

## The idea

A cairn is a marker built one stone at a time. It helps people find a route without turning the landscape into noise. That is a useful model for the server too: explore, contribute, and leave something helpful behind.

## What to expect

- Minecraft: Java Edition survival
- A small, growing community
- A practical player handbook
- Server systems documented with verified information
- No store funnel, voting campaign, or player-count marketing
