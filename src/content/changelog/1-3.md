## Server update

- Updated server software and plugins. This release required **Minecraft Java Edition 26.1.2**.
- Updated the resource pack to Faithful x64 v26.1.2.
- Minecraft updates since the previous server release added spears, rideable nautilus mounts, nautilus armor, netherite horse armor, new hostile mob variants, natural zombie horses, baby mob improvements, and Golden Dandelions.

## Anvil compatibility

- Added a new anvil compatibility plugin.
- AuraSkills Wisdom discounts and increased anvil level caps from the Enchanting skill now provide better interface feedback instead of incorrectly showing “Too Expensive” for valid combinations.
- The plugin also helps protect items left inside an anvil from being lost during a server restart.

## ExcellentEnchants

ExcellentEnchants added several custom enchants, including a new enchant that grants extra health.

## Update: AuraSkills equipment

AuraSkills stats and traits can now be added to armor, tools, and weapons.

The first use is an upgraded new-player kit. It includes temporary chainmail armor with a modest health and damage-reduction boost—roughly 40–50% more effective health—plus Soulbound so the player keeps it after dying.

The armor cannot be repaired or further enchanted, but it should last long enough for a new player to get established. Players who had already joined could ask Eadrom to reset their spawn-kit lockout.

This work laid the foundation for stat armor, tools, and weapons as new gearing options in future releases.
